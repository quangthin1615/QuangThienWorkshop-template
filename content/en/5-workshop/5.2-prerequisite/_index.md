## Prerequisites

- An AWS account.
- Access to the AWS Management Console.
- A Windows or Linux computer with an SSH client.
- A key pair for connecting to the EC2 instance.
- An email address for confirming the SNS subscription.
- Basic knowledge of EC2, VPC, IAM, and CloudWatch.

## Workshop Environment

The lab is deployed in the `ap-southeast-2` (Sydney) AWS Region.

The EC2 instance uses Amazon Linux 2023 and the `t3.micro` instance type.
