During the **First Cloud AI Journey** program, I had the opportunity to learn and practice various topics related to **Cloud Computing, Networking, and Cloud Security**. Through the hands-on workshops and project development process, I gained a better understanding of how networking and security concepts can be applied in a real-world cloud environment.

## 1. Overall Evaluation

### 1.1. Networking and Cloud Knowledge

One of the most useful parts of the program for me was the opportunity to practice networking concepts directly on AWS.

Through working with components such as **VPC, Subnet, Route Table, Internet Gateway, Security Group, and Network ACL**, I gained a better understanding of how to design, divide, and control a network system in the Cloud.

Previously, I mainly learned networking through theoretical concepts. By practicing directly on AWS, I was able to better understand the relationship between different network components and how data can be allowed or restricted when moving between resources.

### 1.2. Applying Knowledge to My Project

During my project development, I focused on **data protection and encryption**, specifically **selectively encrypting important components of JPEG images**.

The goal of my project is to reduce processing time by encrypting only the necessary components while still ensuring that the encrypted image cannot be normally viewed or used without the decryption key.

Through learning about Cloud and Networking, I realized that data protection does not only depend on the encryption algorithm. It is also related to **how data is stored, transmitted, and accessed**.

These concepts gave me a broader perspective on how I can improve my project and make it more secure when deployed in a Cloud environment.

### 1.3. Network Security Knowledge

The topics related to **Security Groups, Network ACLs, and IAM** helped me better understand how access to AWS resources can be controlled.

In particular, allowing only necessary connections helped me understand the principles of **Least Privilege** and **Network Isolation** more clearly.

These are areas that I would like to continue studying because they can be applied to building Cloud systems that better protect data and prevent unnecessary access.

### 1.4. Troubleshooting Skills

During the hands-on Labs, I encountered several issues related to network configuration, access permissions, and connectivity between resources.

Checking **Route Tables, Security Groups, Network ACLs, and logs** helped me develop a systematic approach to troubleshooting instead of randomly changing configurations.

As a result, I improved my ability to analyze problems and troubleshoot issues related to AWS networking.

---

## 2. What I Liked Most

What I liked most about the program was the opportunity to **practice directly in the AWS environment** instead of only studying theory.

Creating resources, configuring networks, testing connectivity, and monitoring the system helped me understand the concepts more clearly.

In particular, the knowledge of **Networking and Cloud Security** gave me a stronger foundation for continuing to develop my project in a direction that combines **data protection and Cloud infrastructure security**.

---

## 3. Suggestions for Improvement

In my opinion, the program could include more practical and advanced Labs focusing on **AWS Networking and Cloud Security**.

For example, a complete Lab could follow this process:

**VPC → Public/Private Subnet → Route Table → Security Group → Network ACL → Connectivity Testing → Log Monitoring**

The Lab could then provide several network configuration problems for interns to investigate and troubleshoot themselves.

In addition, practical exercises related to **protecting data during transmission and storage in the Cloud** would be very useful for students who are interested in **Network Security and Cloud Security**.

---

## 4. Suggestions and Future Goals

I would suggest that the program organize more **Deep Dive sessions on Networking and Cloud Security**, focusing on practical topics such as:

- Designing Public and Private networks on AWS.
- Dividing and isolating networks using VPC and Subnets.
- Controlling traffic using Security Groups and Network ACLs.
- Analyzing and troubleshooting network connectivity issues.
- Monitoring systems and network activities using CloudWatch.
- Protecting data during transmission and storage.
- Combining data security with Cloud infrastructure security.

In the future, I would like to continue learning more about **AWS Networking, Cloud Security, and Data Protection**, and apply the knowledge I have gained to my project in order to build a more practical and secure system.
